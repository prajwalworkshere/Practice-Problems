13. Write a program to display first 5 even numbers using any one of the
looping structure of MySQL(3)

DELIMITER //
CREATE PROCEDURE EVEN_NOS()
BEGIN
	DECLARE tempnum INT DEFAULT 1;
	WHILE  tempnum <=5 DO
		SELECT tempnum*2 AS EVENNUMBER;
		SET tempnum=tempnum+1;
	END WHILE;
END//
DELIMITER ;

14. Create a stored function name DISC_CALC that takes two parameters:-
ORIGINAL_PRICE and DISCOUNT_PERCENTAGE. The function should calculate
the discounted price based on the original price and the discount percentage.
The function should return the discounted price.(3)

DELIMITER //
CREATE FUNCTION DISC_CALC(ORIGINAL_PRICE DECIMAL(10,2),DISCOUNT_PERCENTAGE DECIMAL(10,2))
RETURNS INT
DETERMINISTIC
NO SQL
BEGIN
	DECLARE finalprice DECIMAL(10,2);
	SET finalprice= ORIGINAL_PRICE-(ORIGINAL_PRICE*(DISCOUNT_PERCENTAGE/100));
	RETURN finalprice;
END //
DELIMITER ;
